# 검증 기록

작성 환경: Windows / Node v24.19.0.

실행: `node --test tests/*.test.cjs`.

검증 범위:

- v1 예시 문자의 승인금액/상호 추출, 누적 금액 제외.
- 사용자 지정 카드사/감지어, 카드사 비활성화, 구형 설정의 기본 카드사 마이그레이션.
- 중복, 취소 원거래 연결, 해외·불명확 문자 검토 보관.
- 월급 교체, 추가 수입, 고정비 예약 및 초과분, 음수 잔액.
- KST 자정, 연도 경계, 윤년, 월별 비교, 주간 일별 추이, 연간 합계.
- 보고서 지문 재사용, 늦게 도착한 AI 응답의 덮어쓰기 차단.
- 검토함 처리 후 문자 재수신 중복 방지.
- Gateway 인증, 개인 데이터 필드 차단, 결과 스키마 검증, 배치 ID 검증.
- 호출량 제한, 재시작 후 제한 지속, 결과 캐시, 공급자 장애 응답 비밀정보 제거.
- 동시 요청 차단과 결산 배치 HTTP 왕복.

추가 검증: 저장 전 마스킹, 기존 장부 개인정보 변환, SHA-256 문자 지문, 승인/취소/환불 별도 기록, 부분취소 누적액 제한, 카드 식별자 혼동 방지, SideStore 릴리스 URL 생성, 자체 서버 없는 AI 모드.

최종 실행 결과: 34개 테스트 통과. 아이폰 빌드와 실제 API 호출은 여전히 미실행입니다.

미실행:

- `ios/Tests/LedgerBridgeTests.swift`: JavaScriptCore/iOS SDK가 필요한 테스트.
- Xcode 빌드, 시뮬레이터, 실제 아이폰 설치·위젯·잠금 상태 자동화.
- PhotosPicker → Vision OCR, Wallet Transaction 자동화, SMS/이메일 자동화의 실제 iPhone 16 Pro 동작.
- 실제 Groq/OpenRouter/Gemini API 호출. HTTP 통합 테스트는 공급자 응답을 대역으로 주입.
- GitHub Actions 원격 실행 및 Gateway 배포.

JS 테스트 통과는 iOS 앱 빌드나 실기기 자동화 검증을 대신하지 않습니다. 작성한 macOS CI는 향후 저장소 업로드 후 실행할 수 있는 검사 정의입니다.
