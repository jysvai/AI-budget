# API 준비

첫 공급자는 Groq로 선택합니다. 키 하나로 시작할 수 있으며 다른 API를 동시에 만들 필요는 없습니다.

- 발급: https://console.groq.com/keys
- 공식 안내: https://console.groq.com/docs/quickstart
- 무료 티어 설명: https://community.groq.com/t/is-there-a-free-tier-and-its-limits/790 (정확한 제한은 콘솔의 Limits에서 확인)

본인 계정으로 로그인/가입 → API Keys → 키 생성. 로그인·이메일 인증·2단계 인증은 본인이 진행합니다. 생성된 키를 채팅이나 GitHub 소스에 붙여 넣지 않습니다.

개인 사용은 앱 → 설정 → 개인 API → Groq → API 키 입력 → 저장 순서입니다. 키는 아이폰 Keychain에 저장되고 앱은 Groq에 직접 요청합니다.

현재 결정은 **자체 서버 없이 아이폰에서 직접 호출**하는 방식입니다. 기존 ‘기본 제공 AI/Gateway’ 모드는 앱에서 제거했습니다. 공용 비밀키를 IPA에 넣지 않으므로 개인 API 키를 한 번 연결해야 AI를 사용할 수 있습니다. 키를 연결하지 않아도 기기 내 집계와 규칙 결산은 동작합니다. 외부 AI API를 이용할 때에는 해당 공급자의 서버로 집계가 전송되며, 완전 오프라인과는 다릅니다.

연결된 브라우저와 로그인된 계정이 있으면 에이전트가 발급 화면 탐색 및 설정을 도울 수 있습니다. 이번 세션에서는 브라우저 도구가 `No browser is available`을 반환해 계정이나 키 생성 화면에 접근하지 못했습니다. 아직 키 발급·외부 계정 생성·서버 배포·실제 API 호출은 하지 않았습니다.

사용자가 서비스 계정 인증을 완료해도 API 키 생성은 지속적인 접근 권한을 만드는 작업이므로, 브라우저 자동화가 발급 버튼을 누르기 전에는 해당 작업에 대한 확인을 받을 수 있습니다. 키 값 자체를 채팅에 공개할 필요는 없습니다.
