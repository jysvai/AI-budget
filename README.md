# 모아 가계부 — iOS 하이브리드 MVP

> 최신 결정: **런타임은 아이폰 단독, 자체 서버/PC 중계 없음.** iPhone 16 Pro에서 2024년 iOS 18, 2025년 iOS 26, 2026년 iOS 27을 모두 포괄하도록 최소 버전을 iOS 17로 유지하고 새 OS 전용 API에 의존하지 않습니다. 설치는 [iloader 가이드](docs/iloader-install.md)를 따릅니다. 타사 푸시 직접 감시는 iOS 공개 API상 불가능하므로 Wallet 거래 자동화, SMS·이메일 자동화, 기기 내 푸시 화면 OCR 순으로 보완합니다.

사용자는 앱에서 월급·고정비·카드사·분석 방식을 설정하고, 안내에 따라 카드별 수집 자동화와 결산 자동화·위젯을 한 번 연결합니다. 코드나 설정 파일을 수정하는 과정은 **개발·배포 담당자에게만** 해당합니다.

## 현재 구현

- SwiftUI: 현황, 거래, 수동 입력, 검토함 처리, 월급 확인, 고정비, 카드사 선택·직접 추가, 푸시 화면 가져오기, 설정 안내.
- App Intents: 문자·이메일 거래 기록, Wallet 거래 기록, 스크린샷 OCR 기록, 예약 결산 실행. iPhone 16 Pro 액션 버튼 단축어로 OCR 기록을 한 번에 실행할 수 있습니다.
- 수집 보완: Apple Wallet 거래 자동화 → 카드사 SMS/이메일 자동화 → 사용자가 선택한 푸시 캡처의 기기 내 Vision OCR. OCR 이미지와 원문은 저장·업로드하지 않습니다.
- WidgetKit: 소형/중형 생활비 위젯, 업데이트 시각과 미확정 거래 표시.
- 공유 계산 엔진: 원 단위 정수, KST 날짜, 예상 수입/실제 수입 구분, 구독 중복 차감 방지, 중복 문자, 명확한 전액 취소, 검토함.
- 일간·주간·월간·연간 집계, 이전 기간 비교, 연간 12개월 합계. AI는 여러 결산을 한 요청으로 처리.
- AI: 개인 Groq/OpenRouter/Gemini 또는 기기 내 결산. 개인 키는 Keychain에 저장하며 앱이 공급자에 직접 연결합니다. Groq는 분석용 5개 모델을 한도·가용성에 따라 자동 순환합니다.
- Gateway: 초기 설계의 참고 코드만 남아 있고 현행 앱에는 연결되지 않습니다.
- 로컬 장부: App Group 파일, 프로세스 간 NSFileCoordinator, atomic write, 직전 정상본 백업.

## 검증 상태

Node로 공유 계산 엔진과 Gateway 통합 테스트를 실행할 수 있습니다. iOS 실행환경은 JavaScriptCore이므로 별도 네이티브 테스트도 작성했습니다.

```powershell
npm.cmd test
```

이 프로젝트를 작성한 환경은 Windows이며 Xcode/Swift가 없습니다. **iOS 빌드·시뮬레이터·실기기 테스트는 아직 실행하지 않았습니다.** macOS CI 워크플로는 작성만 했으며 원격 실행하지 않았습니다. 실제 API 키가 제공되지 않아 공급자 호출은 테스트 대역으로 검증했습니다.

## Mac에서 앱 생성·실행 (개발자용)

1. Xcode와 XcodeGen을 설치합니다.
2. `ios/project.yml`의 식별자는 `com.yunseok.aibudget`, `group.com.yunseok.aibudget`입니다. 다른 계정으로 배포할 경우 본인 식별자를 사용합니다.
3. 프로젝트를 생성합니다.

```sh
cd ios
xcodegen generate
open AIBudget.xcodeproj
```

4. 앱과 위젯의 Signing Team을 지정하고 동일 App Group 권한을 활성화합니다.
5. iPhone 시뮬레이터에서 빌드 및 XCTest를 실행한 후 실제 아이폰에 설치합니다.
6. 앱 설정 → 예산/고정비 → 카드사 선택 → 알림 → 카드 수집/결산 자동화 안내 → 위젯 순으로 진행합니다.

무료 서명/사이드로드 도구가 App Group 등 필수 entitlement를 유지하는지 실제 설치본으로 확인해야 합니다. 서명 방식은 아직 확정하지 않았고 IPA도 아직 생성하지 않았습니다.

## `gateway/` 참고 코드

초기 서버형 설계를 검증한 코드와 테스트를 기록 목적으로 보존합니다. 현행 iOS 앱에는 Gateway URL이나 등록 토큰 설정이 없고 이 코드를 호출하지 않습니다. 삭제해도 아이폰 앱 기능에는 영향이 없습니다.

## 실기기 출시 전 확인 사항

1. Xcode 빌드/네이티브 테스트 통과 및 실제 SMS 본문 매개변수 연결.
2. 잠금·재부팅 후 첫 잠금 해제·저전력·오프라인 상태에서 자동화 동작.
3. 실제 카드사 문자로 파서 확대. 현재 문서에 나온 `금액 → 가맹점` 형식만 보수적으로 지원하며 모르는 형식은 검토함으로 이동합니다.
4. 개인 API 공급자 키 설정, 무료 한도와 데이터 처리 약관 확인, 실제 한국어 결과 평가.
5. API 시간초과/네트워크 끊김에서 장부 보존과 다음 결산 재시도 확인.
6. 위젯 App Group 접근, 알림 허용/거부, 월급 알림 날짜와 말일 처리.
7. 장부 복원 UI, 거래 수정 UX, 고정비 설정의 월별 이력, 앱 아이콘/접근성/디자인 마무리.

상세한 결정 사항과 한계는 [v2 제품 명세](docs/product-spec-v2.md)를 참고하세요. 기존 v1 파일은 배경 자료로 보존합니다.
